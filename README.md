# 乡韵智创 (XiangYun AI)

**AI赋能乡村产业，智创农文旅新未来。**

乡韵智创是一款面向农业产业发展与乡村文旅融合的AI智能服务平台，通过人工智能技术，为农业生产经营、乡村产业规划、文旅资源开发、品牌宣传及数字内容创作提供智能化支持。

## 功能特性

### 🌾 AI助农
- **行业分析**：农业产业发展顾问，提供种植业、林业、畜牧业、渔业等6大领域的专业分析
- **视频制作**：农产品品牌宣传、乡村丰收记录、农业企业形象等专属模板

### 🏞️ AI文旅
- **行业分析**：目的地文旅发展顾问，提供地域文化、自然资源、农旅融合等多维度分析
- **视频制作**：景区形象宣传、乡村旅游推广、地方美食介绍等文旅专属模板

### 🎬 AI视频创作
- 模板创作：丰富的助农和文旅专属视频模板
- 文生视频：通过文字描述生成宣传视频
- 图生视频：上传图片生成动态视频

### 🤖 模型服务中心
- 官方聚合服务：多模型统一入口
- 自定义API：支持OpenAI、Anthropic、DeepSeek等多种服务商

## 技术栈

- Vue 3 + Vite
- Vue Router（路由管理）
- Pinia（状态管理）
- Lucide Vue Next（图标库）
- LocalStorage（数据持久化）

## 项目结构

```
src/
├── assets/          # 静态资源
├── components/      # 公共组件
├── layouts/         # 布局组件
├── views/           # 页面组件
│   ├── Home.vue           # 首页
│   ├── Agriculture.vue    # 助农（行业分析+视频制作）
│   ├── Tourism.vue        # 文旅（行业分析+视频制作）
│   ├── VideoStudio.vue    # 通用视频创作中心
│   ├── ModelCenter.vue    # 模型服务中心
│   ├── Profile.vue        # 个人中心
│   ├── Auth.vue           # 登录注册
│   └── Settings.vue       # 设置
├── router/          # 路由配置
├── stores/          # 状态管理
├── utils/           # 工具函数
└── mock/            # Mock数据
```

## 安装运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```
